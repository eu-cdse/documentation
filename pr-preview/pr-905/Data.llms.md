# Data & Information

This section provides an overview of the EO data available from Copernicus Data Space Ecosystem. The data offer is gradually extending.

> **NOTE:**
>
> Browse [SentiWiki](https://sentiwiki.copernicus.eu/web/sentiwiki) to discover more about the Copernicus Sentinel Missions.

> **NOTE:**
>
> Occasionally, operational events may affect the availability of Sentinel satellite data.  
> Visit [SentiBoard](https://operations.dashboard.copernicus.eu/index.html) for a real-time view of Sentinel satellite data availability and processing status.
